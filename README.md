## How to reproduce

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`) and verifies the copy by PNG
magic, size and sha256. Run it twice: both runs write the same bytes.
